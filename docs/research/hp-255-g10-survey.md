# HP 255 G10 research case

An owner-supplied preflight archive was imported offline on 2026-09-22. The
archive and normalized report remain outside Git in a restricted private
workspace. The owner has not reviewed an allowlist export for publication, so
this repository withholds the archive-derived technical observations and
collection findings. The private report is the source for any later review.

[HP's product-family datasheet](https://h20195.www2.hp.com/v2/GetPDF.aspx/c08513971.pdf)
lists the Ryzen 3 7330U among the HP 255 G10 processor options.
[AMD's processor page](https://www.amd.com/en/products/processors/laptop/ryzen/7000-series/amd-ryzen-3-7330u.html)
identifies that processor as Barcelo R. These public facts do not identify
the processor, board revision, or installed firmware of a particular unit.

The catalog entry is research-only. It has no exact HP coreboot board target
or firmware recipe. A processor relationship can guide future source review;
it cannot supply a laptop's memory, EC, GPIO, flash, or security configuration.
No command from the private survey was rerun. No physical firmware device was
accessed. Momiji is excluded from physical experimentation.
