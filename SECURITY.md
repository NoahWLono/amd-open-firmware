# Security policy

This project handles untrusted archives and build inputs. Please report a
suspected vulnerability privately to the repository owner using GitHub's
private vulnerability reporting feature if it is enabled. If that feature is
not available, use an existing private channel with the owner. Do not post
private survey data, device identifiers, firmware blobs, or a working exploit
in a public issue. This repository does not designate a security email inbox.

Reports should identify the affected project version, input class, expected
boundary, observed behavior, and a minimal synthetic reproducer. The project
owner will assess the report and coordinate an upstream report if coreboot,
openSIL, or another dependency is affected. No response-time guarantee or
bounty program is offered.

The research scope is offline metadata and build integrity. It does not
authorize probing physical firmware devices or bypassing platform protections.
